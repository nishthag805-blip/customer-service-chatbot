# Customer Service Chatbot 🤖

A simple rule-based customer service chatbot built with Python.

## Features

* Answers basic customer questions
* Order tracking information
* Shipping information
* Refund information
* Return and exchange information
* Payment information
* Customer support contact information
* Opening hours
* Simple keyword-based NLP
* Runs directly in the terminal

## Technologies Used

* Python
* Regular Expressions (`re`)
* Basic NLP / keyword matching

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/nishthag805-blip/customer-service-chatbot.git
```

### 2. Open the project

```bash
cd customer-service-chatbot
```

### 3. Run the chatbot

```bash
python chatbot.py
```

On Windows, you can also use:

```bash
py chatbot.py
```

## Example

```text
Bot: Hello! 👋 How can I help you today?

You: Where is my order?

Bot: You can track your order using the tracking number
provided in your order confirmation email.

You: How long does shipping take?

Bot: Standard shipping usually takes 3–5 business days.
Express shipping usually takes 1–2 business days.
```
